## Projects

### [智能选校 Agent](https://github.com/xiaogongzhuuu/tucebida-study-abroad) `DeepSeek + RAG + FastAPI`

面向留学顾问业务的 AI 选校推荐系统。学生画像智能解析 → 多维度匹配打分 → 冲刺/匹配/保底三档分级 → SSE 流式生成报告。116 个项目结构化入库，覆盖英港新 33 所院校。

### [RAG 文档问答助手](https://github.com/xiaogongzhuuu/rag-assistant) `GPT-4 + LangChain + FAISS`

面向企业私有知识库场景，构建文档解析 → 向量检索 → 上下文增强生成的完整 RAG 链路，支持 PDF / Markdown 上传与多轮对话。已部署 [Hugging Face Spaces](https://huggingface.co/spaces/xiaogongzhuuu/rag)。

### [医学知识图谱 + RAG 混合问答](https://github.com/xiaogongzhuuu/data-mining-course) `Neo4j + ChromaDB + LLM`

面向中医名医经验传承场景，大模型实体抽取构建 Neo4j 知识图谱，结合 ChromaDB 向量检索，实现结构化推理与非结构化检索的混合问答。

### [LLM 应用开发实践](https://github.com/xiaogongzhuuu/rag-agent-project) `LangChain · Agent · ReAct`

从 API 调用、Prompt Engineering 到 RAG、Agent ReAct 自主推理的完整实践，覆盖工具调用与任务编排。
