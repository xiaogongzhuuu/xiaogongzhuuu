## Projects

### RAG & Agent Applications

**[RAG 文档问答助手](https://github.com/xiaogongzhuuu/rag-assistant)** `GPT-4 + LangChain + FAISS`

面向企业私有知识库场景，构建了文档解析 → 向量检索 → 上下文增强生成的完整 RAG 链路，支持 PDF / Markdown 上传与多轮对话问答。已部署 [Hugging Face Spaces](https://huggingface.co/spaces/xiaogongzhuuu/rag)。

> *Demo: 用户上传 PDF → 语义检索 → AI 精准回答*

**[医学知识图谱 + RAG 混合问答](https://github.com/xiaogongzhuuu/data-mining-course)** `Neo4j + ChromaDB + LLM`

面向中医名医经验传承场景，通过大模型实体抽取构建 Neo4j 知识图谱，结合 ChromaDB 向量检索，实现结构化知识推理与非结构化文献检索的混合问答系统。

**[LLM 应用开发实践](https://github.com/xiaogongzhuuu/rag-agent-project)** `LangChain · Agent · ReAct`

从 API 调用、Prompt Engineering 到 LangChain RAG、Agent ReAct 自主推理的完整 LLM 应用技术栈实践，覆盖工具调用、多轮对话与任务编排链路。
